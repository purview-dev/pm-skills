Dependency graph: how should it be laid out?

Real data from planning/ today: 8 open items, 9 Depends on links, 7 of them to done items. Arrows point from the item that has to come first to the item that waits for it. Every node links to its feature page.

A

One flow, done items as faded chips

Left to right in the order work has to happen. Done prerequisites show as small dashed "✓" chips, so every link is drawn and you can see what has already cleared. Milestone is a tag on each node. Items with no links sit in a tray underneath.

B

Milestone lanes

Same flow and the same done chips, but each milestone gets its own band, in strategy order. Shows how each area hangs together. Arrows that cross between milestones stand out. Uses more height.

C

Open items only, done count on the node

Matches the item's wording most literally: only open items are nodes. A done prerequisite is a "✓ 4 done" line on the node, not a node or arrow. Least clutter, but today it is 2 arrows, and you can't see which done items it was waiting on without opening it.

Common to all three: you can pan and zoom, the active item is highlighted, and blocked items have a dashed border. Click to pick, or tell me what to change.
