# Inbox

The parking lot. One file per idea, bug, question, or piece of
inspiration, written by `pm-park` (from the user or the agent), `pm-bug`
for defects with a severity and reproduction block, and `pm-discover`.
Discussed with `pm-shape`. Triaged by `pm-review`.

File name: `YYYY-MM-DD-HHMM-<slug>.md`. One file per idea means parallel
sessions never conflict. Ideas are kept verbatim; later thoughts are
appended under `## Notes`.

Files marked `Discuss: yes` are waiting for a `pm-shape` session. Files
with a `Reviewed` date were kept on purpose during a review. A
`Kind: bug` file also carries `Severity` (blocker, major, minor,
cosmetic), `Affects`, and a `## Reproduction` block; `blocker` bugs are
fixed before the active item continues.
