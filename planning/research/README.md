# Research

One report per `pm-discover` run: an analysis of the existing product, its
history and usage, or the answer to one product question. Every finding
cites its evidence. Opportunities found here are parked in `inbox/` with a
link back to the report.

File name: `YYYY-MM-DD-<slug>.md`. Reports are never edited after the run
that wrote them; a later run writes a new report.
