# Briefs

One file per shaped idea, written by `pm-shape` after every answer so a
discussion survives compaction and new sessions. A roadmap item links to
its brief with `Brief:`, and `pm-next` passes the brief to the design
skill.

File name: `R-NNN-<slug>.md` for roadmap items, or `YYYY-MM-DD-<slug>.md`
for ideas that are not on the roadmap. Briefs are never deleted; their
`Status` records the outcome.
